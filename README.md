# CSE Hub

A personal Computer Science knowledge-management dashboard — save, organize, browse and
revisit resources, notes, sessions, courses, project ideas, internships, hackathons and
certifications in one place.

- **Frontend:** React + Vite + TypeScript + Tailwind CSS + React Router
- **Backend:** Java + Spring Boot + Spring Data JPA + MySQL + Maven

See **SETUP_GUIDE.md** for full setup instructions.

```
cse-hub/
├── backend/     Spring Boot REST API (Java, MySQL)
├── frontend/    React + Vite + TypeScript SPA
└── SETUP_GUIDE.md
```
